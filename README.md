# Compliance Copilot AI

An Agentic AI-powered Legal & Regulatory Intelligence Platform for business incorporation, compliance monitoring, and proactive legal decision support.

## Tech Stack

- Frontend: React + Vite + Tailwind CSS
- Backend: FastAPI
- Database: SQLite
- AI: Modular Agent Architecture
- OCR: PaddleOCR
